# Card Master データ

仕様書47番の通り、初期開発ではCard MasterをGitHub上のJSONで管理する。

- `cards/subordinates.json` / `spells.json` / `fields.json`：通常カードのマスターデータ（仕様書5〜7番の形式）
- `cards/players.json`：Player（アバター/リーダー）のマスターデータ（仕様書8番の形式）。プレイヤーアカウントのID（`playerId`として各所で使われる別概念）とは異なる点に注意
- `packs/packs.json`：Packのマスターデータ（仕様書14番の形式）

**現時点でのサンプルデータについて**

ここに含まれるカード・パックはPhase 1（Card Master読み込みの動作確認）用のサンプルであり、実際のゲームバランスやカード効果を意図したものではない。カードの`effectText`は仕様書30番の通り自由記述だが、効果を実際に解釈・処理するロジック（カード効果DSL）は仕様書52番により未確定のためPhase 1時点では未実装。

パックのレアリティ区分・排出率・カードとレアリティの対応関係も仕様書14, 52番により未確定のため、`packs.json`にはスロット構成のみ記載し、カードIDとレアリティの対応は含めていない。Phase 8（パック実装）着手時に確認する。
